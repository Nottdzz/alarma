# Documento de Diseño Frontend (UI/UX - Guía de Estilo)

**Proyecto:** Sistema de Gestión de Horarios, Alarmas y Estado Emocional Escolar  
**Versión:** 1.0.0  
**Enfoque Visual:** Dashboard Escolar Moderno, Amigable y Claro  
**Stack Visual:** HTML5, CSS3 (Variables CSS / Flexbox / CSS Grid), JavaScript (Vanilla ES6+)

---

## 1. Filosofía de Diseño y Concepto Visual

El diseño visual está orientado a **estudiantes escolares**, por lo que debe transmitir organización, serenidad y energía positiva sin caer en distracciones ni sobrecargas visuales.

### Principios Fundamentales
* **Claridad Estructural:** Organización en tarjetas (cards) y bordes redondeados suavemente para mantener la información limpia.
* **Jerarquía Clara:** Uso explícito de contrastes en tipografía para facilitar la lectura rápida de horarios y tareas.
* **Feedback Inmediato:** Transiciones suaves e indicadores de color claros para los estados de las alarmas (activa/inactiva) y el registro emocional.

---

## 2. Paleta de Colores (Color Palette)

La paleta utiliza la metodología de variables CSS (`:root`) para facilitar su personalización y mantenimiento.

### 2.1. Variables CSS de Color
```css
:root {
  /* Colores Principales (Brand Colors) */
  --color-primary: #4F46E5;       /* Índigo principal (Botones, encabezados destacados) */
  --color-primary-hover: #4338CA; /* Índigo oscuro (Hover en botones) */
  --color-secondary: #0EA5E9;     /* Azul cian (Acentos y tarjetas de información) */

  /* Colores de Estado (Feedback & Status) */
  --color-success: #10B981;       /* Verde (Alarmas activas, estados positivos) */
  --color-warning: #F59E0B;       /* Ámbar (Alertas moderadas, estado emocional neutro) */
  --color-danger: #EF4444;        /* Rojo (Eliminar, conflictos de horario, alarmas sono) */

  /* Neutrales y Fondos (Neutral & Backgrounds) */
  --bg-main: #F8FAFC;             /* Fondo general de la aplicación */
  --bg-surface: #FFFFFF;          /* Fondo de tarjetas, modales y tablas */
  --bg-sidebar: #0F172A;          /* Fondo de barra lateral o menú de navegación */
  
  /* Textos y Bordes */
  --text-main: #1E293B;           /* Texto principal (Alto contraste) */
  --text-muted: #64748B;          /* Texto secundario o etiquetas de ayuda */
  --border-color: #E2E8F0;        /* Bordes sutiles para tarjetas y separadores */
}
